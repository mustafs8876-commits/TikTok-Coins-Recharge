# Mensory Builder — TikTok search

Распакуйте архив целиком. Для запуска на Windows дважды щёлкните start-local.bat; браузер откроет страницу. Оставьте окно сервера открытым.

Нужен Node.js 18 или новее. Не открывайте index.html напрямую: поиск, фотографии и публичная статистика профилей загружаются через локальный API.

Справа от аватара отображаются подписки, подписчики и лайки столбиком. Если TikTok не отдаёт статистику, для неё показывается тире.
